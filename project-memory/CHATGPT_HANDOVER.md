# ChatGPT handover

Project: You Matter

Summary:
This project is a wellbeing-focused website built around the idea that small actions become visible, collective change. The current repository is a static homepage recovery of the original concept. It introduces the project, explains the idea, and presents three adventure tracks: Gratitude Garden, Nature Mosaic, and Built From Kindness.

Current state:
- Homepage is complete and functioning as a standalone static page.
- Visual tone is warm, thoughtful, and human.
- The three adventure cards are present but the linked subpages are not implemented locally.
- Submission flows, persistence, moderation, and admin tooling are not yet built.

Key files:
- `index.html` — homepage entry point
- `assets/style.css` — visual design
- `project-memory/VISION.md` — project philosophy and creative principles
- `project-memory/ADVENTURES.md` — summary of each adventure and missing implementation areas
- `project-memory/DECISIONS.md` — key project decisions
- `project-memory/STATUS.md` — current working state and risks

Important constraints:
- The project is intentionally grounded in positive psychology and collective wellbeing, not profit-driven or performance-driven design.
- Do not make the site feel corporate, clinical, or overly polished.
- Keep the tone personal, quiet, and invitational.

Recommended next step:
Implement at least one complete adventure flow end-to-end, including a local page, submission form, storage model, and visible community output. Once one adventure works, the other two can follow the same structure.
