# Project memory rule

Before doing any substantive work on this repository, read the current project memory files first:

- `project-memory/VISION.md`
- `project-memory/ADVENTURES.md`
- `project-memory/DECISIONS.md`
- `project-memory/STATUS.md`
- `AGENTS.md`

## Required behavior
- Keep the project aligned with its purpose: small actions, wellbeing, shared contribution, and visible collective change.
- Preserve the project’s tone: warm, thoughtful, human, and non-clinical.
- Prefer incremental, scoped changes over large rewrites.
- Do not introduce unnecessary frameworks, complexity, or backend architecture without a clear reason.
- If work changes the product direction, update the memory files to reflect the new state.

## Current project state
- The homepage exists and works as a static export.
- Adventure pages and persistent functionality are still missing.
- Future work should continue from this baseline rather than resetting the project’s intent.
